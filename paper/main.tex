\begin{abstract}

Large Language Models (LLMs) are increasingly transforming software engineering
by assisting developers with code generation, debugging, optimization, and
problem solving. Traditionally, computer science students develop algorithmic
problem-solving skills through extensive practice with data structures,
algorithms, and LeetCode-style programming problems.

This research investigates whether optimized prompt engineering can improve
LLM-assisted algorithmic problem solving and examines how AI-assisted
programming may influence the skills traditionally developed through
algorithmic practice. We propose an experimental framework that compares
three problem-solving strategies: baseline prompting, optimized prompting,
and a structured AI-assisted workflow.

The proposed framework evaluates generated solutions using multiple metrics,
including correctness, algorithm and data structure selection, computational
complexity, and runtime performance. A benchmark dataset of LeetCode-style
problems covering multiple algorithmic categories is used to provide a
controlled environment for comparison.

Rather than assuming that prompt engineering will replace traditional
algorithmic knowledge, this study investigates whether it can complement or
reshape existing problem-solving practices. The research aims to provide an
empirical framework for examining how the increasing use of LLMs may influence
algorithm training, technical interview preparation, and the evolving skill
requirements of software engineers.

\end{abstract}


\section{Introduction}

Large Language Models (LLMs) are rapidly changing the way programming tasks
are performed. Modern AI systems can generate code, explain algorithms,
identify implementation errors, and suggest potential optimizations. As these
capabilities continue to improve, software developers increasingly interact
with AI systems as part of their development workflow.

Traditionally, computer science students develop algorithmic problem-solving
skills through courses, textbooks, programming exercises, and online coding
platforms such as LeetCode. These activities emphasize data structures,
algorithm design, computational complexity, and independent implementation.
Extensive practice is also commonly used as preparation for technical software
engineering interviews.

The emergence of LLM-assisted programming introduces a different approach to
algorithmic problem solving. Instead of independently designing and
implementing every solution, a developer can describe a problem to an LLM,
request multiple algorithmic approaches, compare their computational
complexities, and ask the model to optimize or verify the resulting code.

This creates a potential shift in the traditional programming workflow:

\begin{center}

Problem Understanding
$\rightarrow$
Algorithm Design
$\rightarrow$
Implementation
$\rightarrow$
Testing

\end{center}

toward an AI-assisted workflow:

\begin{center}

Problem Understanding
$\rightarrow$
Prompt Engineering
$\rightarrow$
AI-Generated Solutions
$\rightarrow$
Human Verification
$\rightarrow$
Optimization

\end{center}

The emergence of this workflow raises an important question for computer
science education and software engineering preparation. If LLMs can
successfully generate and optimize solutions to algorithmic problems, the
relative importance of traditional problem-solving practice may change.
However, effective use of AI systems still requires users to formulate
appropriate instructions, evaluate generated solutions, recognize inefficient
approaches, and verify correctness.

Therefore, prompt engineering should not necessarily be viewed as a replacement
for traditional algorithmic knowledge. Instead, it may represent an additional
skill that complements algorithmic reasoning and changes how programming
problems are approached.

This research investigates this potential transition by proposing a controlled
experimental framework for comparing different prompting strategies on
LeetCode-style algorithmic problems. The study evaluates whether structured
prompting can improve solution quality and examines the implications of
AI-assisted programming for future software engineering skills.

\section{Conclusion}

Large Language Models are increasingly changing how software developers
approach programming tasks. This research proposes an experimental framework
for investigating whether prompt engineering can improve algorithmic
problem-solving performance and how AI-assisted programming may influence
traditional algorithm training.

The proposed framework compares baseline prompting, optimized prompting, and
a structured AI-assisted workflow using a benchmark of LeetCode-style
algorithmic problems. Generated solutions are evaluated using correctness,
algorithm selection, computational complexity, and runtime performance.

The objective of this research is not to argue that traditional data
structures and algorithms knowledge will become unnecessary. Instead, it
examines whether the skills required for algorithmic problem solving may
gradually expand to include prompt design, AI-assisted reasoning, solution
verification, and optimization.

Because the empirical evaluation has not yet been completed, this study does
not make definitive claims about the effectiveness of prompt engineering.
Future experiments will provide quantitative evidence for determining whether
optimized prompting produces measurable improvements over baseline LLM
problem solving.

Ultimately, this research aims to contribute to the discussion surrounding
AI-assisted programming and the evolving skill requirements of future
software engineers.
