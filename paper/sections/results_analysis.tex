\section{Results Analysis Plan}

This section describes the methodology used to analyze experimental results.
The analysis focuses on comparing different prompt engineering strategies and
understanding their impact on algorithmic problem solving.


\subsection{Performance Comparison}

The primary objective of the analysis is to compare the performance of
different prompting strategies:


\begin{itemize}

\item Baseline Prompt.

\item Optimized Prompt.

\item AI-Assisted Workflow.

\end{itemize}


Each approach is evaluated using identical benchmark problems to ensure a fair
comparison.



\subsection{Correctness Analysis}


The first analysis measures whether generated solutions successfully solve the
benchmark problems.


The following metrics are calculated:


\begin{itemize}

\item Overall success rate.

\item Pass rate by difficulty level.

\item Pass rate by algorithm category.

\end{itemize}


The correctness improvement between prompt strategies is calculated as:


\[
Improvement =
\frac{New\ Performance - Baseline\ Performance}
{Baseline\ Performance}
\times 100\%
\]


\subsection{Algorithm Selection Analysis}


Correct solutions are further analyzed based on algorithm quality.


The analysis evaluates:


\begin{itemize}

\item Whether the selected algorithm is optimal.

\item Whether the appropriate data structure is selected.

\item Whether unnecessary complexity is introduced.

\end{itemize}



This analysis investigates whether prompt engineering improves algorithmic
reasoning rather than only code generation.



\subsection{Complexity Analysis}


Generated solutions are compared with known optimal solutions.


The evaluation considers:


\begin{itemize}

\item Time complexity accuracy.

\item Space complexity accuracy.

\item Difference from optimal complexity.

\end{itemize}



For example, a solution with:

\[
O(n^2)
\]

will be considered less efficient than:

\[
O(n)
\]

when the optimal solution requires linear complexity.



\subsection{Difficulty-Based Analysis}


Performance will also be analyzed according to problem difficulty.


The benchmark is divided into:


\begin{itemize}

\item Easy problems.

\item Medium problems.

\item Hard problems.

\end{itemize}


This analysis investigates whether prompt engineering provides greater
benefits for more complex algorithmic tasks.



\subsection{Statistical Analysis}


The study will report:


\begin{itemize}

\item Average performance.

\item Success rate differences.

\item Relative improvement.

\item Distribution across categories.

\end{itemize}


Where sufficient data is available, statistical tests may be applied to
determine whether observed differences are significant.



\subsection{Research Question Evaluation}


The final analysis connects experimental results with research questions.


\textbf{RQ1:}

Whether optimized prompts improve solution correctness.


\textbf{RQ2:}

Whether prompt engineering improves algorithm and data structure selection.


\textbf{RQ3:}

How AI-assisted workflows may influence future software engineering skills.


The conclusions will be based on experimental evidence rather than assumptions.
