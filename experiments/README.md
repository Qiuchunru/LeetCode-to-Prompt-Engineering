# Prompt Experiments


This directory contains different prompt strategies used to evaluate the effect of prompt engineering on algorithmic problem solving.


## Prompt Categories


## 1. Baseline Prompt

Purpose:

Measure the default capability of LLMs without additional guidance.


Example:

Solve this LeetCode problem.


## 2. Algorithm Optimization Prompt

Purpose:

Evaluate whether structured reasoning instructions improve solution quality.


The prompt guides the model to:

- Analyze constraints
- Identify algorithm patterns
- Select data structures
- Optimize complexity


## 3. AI-Assisted Engineering Prompt

Purpose:

Simulate a future software engineering workflow.


The model is instructed to:

- Generate multiple approaches
- Compare trade-offs
- Verify correctness
- Produce optimized code
