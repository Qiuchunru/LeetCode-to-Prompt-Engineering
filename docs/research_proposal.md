# Research Proposal

## Title

Rethinking Algorithm Training in the Era of Large Language Models:

From LeetCode Practice to Prompt Engineering


---

# 1. Research Motivation

Traditional computer science education emphasizes algorithmic thinking,
data structures, and computational complexity.

For decades, software engineering candidates have prepared for technical
interviews through extensive algorithm practice on platforms such as LeetCode.

The traditional workflow is:

```
Learn Data Structures

        ↓

Study Algorithms

        ↓

Solve Hundreds of Problems

        ↓

Develop Problem-Solving Skills

        ↓

Technical Interview Preparation
```


However, the emergence of Large Language Models (LLMs) introduces a new
software engineering workflow.

Developers can now use AI systems to analyze problems, design algorithms,
generate code, and optimize solutions through carefully designed prompts.


The new workflow becomes:

```
Problem Understanding

        ↓

Prompt Engineering

        ↓

LLM-Assisted Solution Design

        ↓

Code Generation

        ↓

Human Verification and Optimization
```


This raises an important question:

Will future software engineers need to spend the same amount of time
practicing algorithm problems, or will prompt engineering become an
important complementary skill?


---

# 2. Research Gap

Existing research has mainly focused on:

- Code generation ability of Large Language Models.
- Benchmark performance on programming tasks.
- Improving LLM responses through prompt engineering.


However, fewer studies investigate the broader educational question:

How will AI-assisted programming change the way computer science students
develop algorithmic problem-solving skills?


This research aims to explore the relationship between:

- Traditional algorithm training.
- Prompt engineering skills.
- AI-assisted programming workflows.


---

# 3. Research Question

The primary research question is:


Can prompt engineering compensate for part of the traditional algorithm
training required for software engineering problem solving?


The study investigates the following sub-questions:


## RQ1

Can optimized prompts improve LLM performance on algorithmic problems?


## RQ2

Can prompt engineering improve algorithm and data structure selection?


## RQ3

How does AI-assisted programming change the skills required by future
software engineers?


---

# 4. Research Hypothesis


## H1

Structured prompt engineering improves the correctness of
LLM-generated algorithm solutions compared with simple prompting.


## H2

Optimized prompts increase the probability of selecting efficient
algorithms and appropriate data structures.


## H3

AI-assisted workflows may reduce the amount of manual trial-and-error
required during algorithm problem solving.


---

# 5. Research Contributions


This research aims to provide the following contributions:


## Contribution 1

A benchmark framework for evaluating LLM-assisted algorithm problem solving.


## Contribution 2

A comparison framework between different prompt engineering strategies.


## Contribution 3

An evaluation methodology beyond simple correctness, including:

- Algorithm selection.
- Data structure selection.
- Complexity analysis.
- Solution explanation quality.


## Contribution 4

A discussion of how software engineering education may evolve in the
Large Language Model era.


---

# 6. Experimental Framework


The experiment compares multiple problem-solving approaches.


## Approach 1: Baseline Prompt

A simple prompt requesting a solution.

Example:

```
Solve this LeetCode problem.
```


## Approach 2: Structured Prompt Engineering

A prompt requiring:

- Constraint analysis.
- Algorithm pattern recognition.
- Data structure selection.
- Complexity comparison.


## Approach 3: AI-Assisted Workflow

A multi-step engineering workflow:

1. Analyze requirements.
2. Generate multiple approaches.
3. Compare trade-offs.
4. Verify edge cases.
5. Produce optimized solution.


---

# 7. Evaluation Metrics


Generated solutions will be evaluated using:


## Correctness

- Test case success rate.
- Runtime errors.
- Failed cases.


## Algorithm Quality

- Algorithm pattern recognition.
- Data structure selection.
- Optimal solution selection.


## Complexity Analysis

- Time complexity accuracy.
- Space complexity accuracy.


## Performance

- Runtime.
- Memory consumption.


---

# 8. Expected Impact


This research aims to provide insight into how AI-assisted programming
may influence future software engineering education and professional
skill requirements.

The goal is not to prove that prompt engineering completely replaces
algorithm knowledge, but to understand how the balance between traditional
algorithm training and AI collaboration may change.
