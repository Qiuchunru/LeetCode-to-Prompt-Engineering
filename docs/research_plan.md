# Research Plan

## Research Topic

From LeetCode to Prompt Engineering:
Investigating the Impact of LLM-Assisted Programming on Algorithmic Problem Solving


## Research Question

The main research question is:

Can optimized prompt engineering reduce the reliance on traditional LeetCode-style algorithm training while maintaining or improving algorithmic problem-solving performance?


## Hypothesis

This project investigates the following hypothesis:

Optimized prompt engineering can improve Large Language Model performance on algorithmic problems by guiding:

- Algorithm pattern recognition
- Data structure selection
- Complexity analysis
- Solution verification


However, prompt engineering is expected to complement rather than completely replace fundamental algorithm knowledge.


## Background

Traditional software engineering interview preparation relies heavily on:

- Data structures
- Algorithms
- Complexity analysis
- Extensive LeetCode practice


With the emergence of Large Language Models, developers can now use AI-assisted workflows:


Problem Understanding

↓

Prompt Engineering

↓

LLM-Generated Solution

↓

Human Verification

↓

Optimization


This research explores whether prompt engineering may become an important skill in future software engineering workflows.


## Research Objectives

This project aims to evaluate:

1. Whether optimized prompts improve algorithm-solving accuracy.

2. Whether prompts improve the quality of algorithm design decisions.

3. Whether AI-assisted programming changes the skills required for future software engineers.


## Experimental Design

The experiment will compare multiple approaches:


### Approach 1: Baseline Prompt

A simple instruction asking the LLM to solve the problem.

Example:

Solve this LeetCode problem.


### Approach 2: Algorithm Reasoning Prompt

A structured prompt requiring:

- Constraint analysis
- Algorithm selection
- Data structure evaluation
- Complexity analysis


### Approach 3: AI-Assisted Engineering Workflow

A multi-step workflow including:

- Generate possible solutions
- Compare approaches
- Optimize complexity
- Verify edge cases


## Evaluation Metrics

Solutions will be evaluated using:


### Correctness

- Test case success rate
- Accepted solutions
- Runtime errors


### Efficiency

- Time complexity
- Space complexity
- Runtime performance


### Algorithm Understanding

- Data structure selection
- Algorithm pattern recognition
- Explanation quality


## Expected Contribution

This project aims to provide insights into:

1. Whether prompt engineering can improve algorithmic problem solving.

2. How software engineering skills may evolve in the LLM era.

3. The changing relationship between traditional algorithm training and AI-assisted programming.
