# From LeetCode to Prompt Engineering

## Research Question

With the rapid development of Large Language Models (LLMs) and Prompt Engineering, 
this project investigates whether traditional algorithmic training methods used by 
Computer Science students, such as extensive LeetCode practice and complexity analysis, 
may shift toward AI-assisted problem solving through optimized prompting techniques.

The main research question is:

> Can optimized prompt engineering improve algorithmic problem-solving performance 
> and reduce the reliance on traditional LeetCode-style algorithm practice?
